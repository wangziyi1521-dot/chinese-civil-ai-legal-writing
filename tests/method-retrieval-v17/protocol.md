# 方法检索能力前向检查

2026-11-15。这是独立于前一轮文风盲评的功能检验，不改写该轮候选未通过的结果。目标是确认已整理的论文方法能够被准确检索、定位并适配到实际写作任务；不将检索成功当作写作质量或个人文风提升的证据。

底层工具须通过51个真实ID的完整卡边界与指定正负查询，以及陈旧行号、ID前缀和路径越界等有意义测试。独立检查所返回的规范语境、适用边界、定位和引页状态是否原样保留，不能把verified当作精确引页已核。

前向任务使用两个已冻结的共同材料：部分交付与合同解除、非合同之债与合同编通则。旧版v1.6.2与带检索工具的候选各由独立上下文完成一次500—700汉字正文，共4份首次输出。两组同用lawpaper、anti-defensive-writing，既有规范和输出要求相同，按各自Skill入口选择参考。没有要求生成者使用特定卡ID或提供预期答案。记录实际路径、命令及实际使用卡片；未使用就记录空，不按结果改组。

功能采用门槛：新工具测试全部通过；候选两次任务均依入口调用检索并选到有实际关系的卡，记录可迁移方法和不适用部分；历史语境、页码待核等限制保留；正文没有引入卡中历史结论、外部事实或新法源作为本稿依据，且没有实质法律条件或未证状态损失。任一失败先修正实际问题并保留初次记录，不能将修复后的结果覆盖初次结果。

旧版调用作为现有使用路径的观察，四份短稿不用于重算前轮风格分数，也不推断统计显著或全题材优势。实际改动只限新增检索脚本、测试和实质写作的窄路由，语言/格式小改不强制加载；不纳入未通过盲评的独立编辑流程。达到功能门槛后可作为方法调用能力更新安装，报告须继续明确：成稿层面的显著优势尚未被前轮证明。

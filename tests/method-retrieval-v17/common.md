# 共同执行要求

使用分配的Skill完成所分配材料中的正文任务，并共同使用lawpaper、anti-defensive-writing。规范全文和假设已经给足，不联网、不增添本稿的法源、外部事实或学说。不将参考中的历史法律结论作为现行规则；所分配Skill可用于组织论证。

按该Skill入口选择必要参考，不读取另一条件、本轮协议、其他输出、历史测试或分数、任何预期卡片ID。只交所分配的500—700汉字正文；过程、卡片说明和教练批注不放入正文。

正文写入指定runs文件；另写同前缀-loads.json，记录实际读取路径及实际执行命令。如果实际使用了论文分析卡，简记卡ID、可迁移步骤、当前材料适配及不适用部分；未使用则记录空，不补造已读或已调用记录。允许按Skill需要另存方法记录，均放本任务runs目录。

# 匿名答卷

## B01 · X

原段以合同价款计算30%，跳过了对争议损失的认定，又把判断违约金是否过高的标准当成了减额公式。

**替换段落**

依《民法典》第585条第2款及合同编通则司法解释第64、65条，法院依当事人以反诉或抗辩提出的请求审查是否调减。乙方须就违约金过高举证，甲方主张约定合理也应提供相应证据。甲方估算的3万元有争议，须依《民法典》第584条认定损失，计入符合可预见性限制的履行利益。若查明损失为3万元，4万元高出约33.3%，超过3.9万元这一判断界线，一般可认定为过分高于损失。是否调减及具体金额，还须结合履行情况、过错等因素判断。迟延七天本身不足以认定恶意。若认定乙方恶意违约，其调减请求一般不获支持。

**关键缺口**　原段以合同价款代替有待查明的违约损失，并把判断违约金是否过高的30%标准当成了调减后的固定数额。

**替换文字**

依《民法典》第585条第2款及合同编通则司法解释第64、65条，乙方可通过反诉或抗辩请求调减，法院依请求审查。乙方应举证证明违约金过高，主张数额合理的甲方也应提供相应证据。甲方估算的3万元存在争议，须依《民法典》第584条查明损失，计入履行后可得利益，并受可预见性限制。若认定损失为3万元，4万元违约金超出损失约33.3%，达到一般可认定为过分高于损失的标准。3.9万元是这一判断的比较基准，是否调减及调减幅度仍须结合履行情况和过错等因素确定。迟延七天本身不足以认定恶意违约。若认定乙方恶意违约，其调减请求一般不获支持。

# 写作对照 · 事先评分表

只根据原题、材料及匿名输出评分。每项 0–2 分，0 为缺失或实质错误，1 为部分做到，2 为完整且可执行。每题最多 8 分，三题共 24 分。逐项记录证据，标记重大错误。比较同一题的输出，不按字数、术语多少或风格相似程度奖励。

| 用例 | 项目 | 2 分所需 |
| --- | --- | --- |
| B01 | 法条与分母 | 引用正确，把违约损失作为分母。区分一般认定线与减额公式。用给定数字说明 4 万超过假设损失 3 万的 130%。 |
| B01 | 启动与证据 | 依当事人提出调整请求，说明争议损失需要证明，并指出至少一项对损失证明有用的材料或具体证明问题。 |
| B01 | 恶意与边界 | 七天本身不足以证成恶意，恶意成立时请求一般不获支持，并有结合法定因素的边界判断。 |
| B01 | 可替换性 | 定位原稿的具体推理缺口，给出可直接替换段落并保留假设，不把 3 万认定为事实。 |
| B02 | 甲的支持核查 | 区分原刊书目真实、63 页内容、正文命题是否受支持。说明政策方案与立法之间的差异。 |
| B02 | 甲的修订 | 只有在调整正文命题后才建议第69页，采用现有引注体例，提供原始链接。 |
| B02 | 乙的引页判断 | 书目、期刊和起讫页可核，正文命题有章节材料支持，原刊第110页待核。给可用节锚，保留待核项。 |
| B02 | 分项可复核 | 两条分别给出结论与依据，保留版本限制，不用题录、刊页区间或转载页码代替精确引页。 |
| B03 | 限定保留 | 保留自行公开、其他合法公开、合理范围、明确拒绝、重大影响须同意五点。 |
| B03 | 含义与不确定性 | 保留针对聚合画像的判断因素和现有材料无法确定结论，避免将条件判断改成肯定结论。 |
| B03 | 范围 | 仅返回一个改写后的第二段，220 汉字以内，引用按原格式，未补案例。 |
| B03 | 清楚简练 | 去掉至少两处原稿的冗余或迂回表达，主体、条件和后果清楚，论旨与原文相同。 |

重大错误包括虚构引注或判决、把无依据结论写成现行规则、改写明确禁止修改的原文。重大错误单列，不能靠其他指标抵销。单题差异仅作该样例观察，三对输出不用于统计显著性或泛化结论。

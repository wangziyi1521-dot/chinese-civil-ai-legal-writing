# 按争点选方法

请使用此Skill的争点入口，仅从已完成深析的论文中，为以下三个研究问题分别选择最多两篇真正相关的材料。一篇足够时列一篇。每项给ID、可借鉴的论证操作、一个适用边界及来源定位。精确引页待核时保留节号。先不写论文正文，也不作当前案件的实体法结论。

## Q1
我想论证合同编的一项减损规则能否用于侵权损失，需要先分清规则缺口和赔偿计算基准。哪些既有论文方法值得读？

## Q2
我讨论受欺诈合同的无效或撤销，既要保留受害人选择，也要考虑第三人效果。怎样挑选相关分析材料？

## Q3
我在写新旧法衔接，希望把法律事实时点、旧法处理能力及终局裁判的影响分别说明。请选材料并指出它能支持哪一步。

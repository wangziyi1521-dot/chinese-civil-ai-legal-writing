# v1.6 文风模块对照预定方案

比较已冻结v1.5与加入文风参考的候选版，均共同使用lawpaper和anti-defensive-writing。4题，两条件各2个独立上下文写作者，每人完成4题，共16个答案、8组描述性对应。默认模型继承同一根代理，不设置不同模型参数；温度/种子不可见。题目及量表在候选文风文件编写前固定。候选按新研究成稿后冻结，再启动生成。

这是材料统一的行文对照，特意不混合独立检索难度；实质质量作为独立门槛，不能以牺牲条件、证据强度、原观点和范围换取语气或篇幅。两名独立评审直接阅读带定位的王利明原文参考及近题他人原文，匿名评全部答案并作8组比较，不读取研究者的候选文风规则。参考片段不用于本轮新增规则的三组取样分析，但可能已在旧语料中出现，不声称对整个Skill完全未见。

按预定四维0—3评分观察行文和对应偏好，报告原始分歧、实质错误及任务范围。不得换量表追求胜出或挑选有利答案。若出现具体实质退化，仅做针对修复并单列复测，保留首轮。各轮由同一写作者完成4题，不能把8组比较当8次完全独立重复；评审均是代理，不等于人类风格识别。无百分比文风相似度，无统计显著性或作者特异性结论。

先完成研究、候选和检查，在本工作区生成可审阅差异与报告，验证后以窄权限更新安装目录并备份，核对安装哈希和技能识别。仅更新本Skill，不改其他技能或配置。

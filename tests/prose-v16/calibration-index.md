# 原文参考定位

本轮匿名指待评条件，不隐藏参考作者。两位评审均实读三组共六个参考自然段，2022两处网页于2026-11-14直接读取成功。网页原文未冻结；2017、2025本地校准原文的研究副本留在工作区，不进Skill。参考未用于本轮九组新增操作的取样，但可能已用于旧语料。参考任务与生成正文任务不完全相同。

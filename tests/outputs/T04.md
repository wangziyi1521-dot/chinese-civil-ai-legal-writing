# 突发污染中预防措施与生态修复的分工

突发污染中的预防措施与生态修复，应按风险控制和生态功能恢复分工。预防贯穿事前隐患排查与事中应急处置。污染仍在扩散时，切断污染源、拦截污染物和监测下游水体的首要任务是限制危害范围，措施强度应随监测结果调整。应急处置结束后，政府组织的影响和损失评估为后续修复提供依据。生态修复应根据受损前的基线及残余损害设定目标，并以修复成效评估检验功能是否恢复。

同一事件可能同时损害公共生态利益与个人权益。水体生态功能受损，应沿法定的生态环境损害赔偿或公益诉讼路径处理。居民因污染产生的医疗支出、经营者的财产损失，须分别依受损主体的请求和相应责任规则认定。污染源尚未切断而部分河段已受损时，控源与修复可以并行。同一清污作业兼具两种功能的，应按措施目的、实际效果与费用凭证区分合理支出，避免同一笔费用重复计入。

## 论证材料清单

- **应急措施和评估的制度依据**。《生态环境法典》第一百一十七条、第一百二十一条、第一百二十四条与第一百二十六条，用于确定应急职责、措施启动及评估衔接。正文以该法典施行后的法律事实为范围，跨施行日材料按时间效力规定另核。[生态环境法典全文](https://www.mee.gov.cn/ywgz/fgbz/fl/202603/t20260313_1146496.shtml) · [最高人民法院关于时间效力的规定](https://www.court.gov.cn/zixun/xiangqing/508001.html)
- **两类损害的请求主体、证明和费用**。《生态环境法典》第一千零六十五条、第一千零七十条、第一千零七十三条、第一千零七十五条、第一千零七十七条和第一千零八十一条，结合《民法典》第一千二百二十九条至第一千二百三十条及第一千二百三十四条至第一千二百三十五条，区分私益索赔与公共生态损害救济。[生态环境法典全文](https://www.mee.gov.cn/ywgz/fgbz/fl/202603/t20260313_1146496.shtml) · [民法典全文](https://tjca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_20cf1a2e1b854924b5caa744c8045d1f.html)
- **措施效果和费用归属**。以应急处置日志、上下游监测记录验证污染扩散与控制时点。以基线资料、损害鉴定、修复方案、验收记录与费用明细验证残余损害、修复效果及费用重叠。[待核：同一事件的官方调查报告、评估原文及可对应的费用凭证]

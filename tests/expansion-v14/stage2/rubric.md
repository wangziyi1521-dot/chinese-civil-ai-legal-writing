# 整稿检验评分表

读任务、固定材料、原稿与实际输出。六项各0–2分，满分12分。重大错误单列。诊断本身不替代修改稿的完成。原始P编号用于核对，不要求修订稿保留。

1. 中心命题与授权。保留分别判断的主张，新增无条件补偿等立法建议与正文分开。
2. 章节功能。实际合并P02/P11重复并说明章序，正文各节有可被下一节使用的中间结论，摘要、引言、结论相互呼应。
3. 实体规则。处理第301、215、209、311各自功能，60%与70%且无其他约定的变化得到不同处分权限判断，未登记不被当作已得产权。
4. 反方与边界。以“合同有效可能侵害乙”这一实质异议为对象，说明债权约束与乙物权地位的分工，保留其他合同效力瑕疵与善意待核，不用交易安全口号代替论证。
5. 救济与证据。第597条的所有权不能转移及请求条件明确，已付款返还和损害赔偿不重复，费用项目指向具体证据、因果和范围条件。
6. 完整交付。含诊断、结构调整理由及完整1800—2400汉字左右短稿，未虚构案例、引文或页码，原文主要矛盾在正文中实际修正。

每项0=缺失/错误，1=部分完成，2=满足。评审另列仍需修改的具体位置和理由。

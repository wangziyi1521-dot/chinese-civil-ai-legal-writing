# 从选题到核心章节

用户的初步题目是“不当得利制度研究”，希望收窄成一篇能完成的规范研究短论文。请基于现有材料提出一个具体研究问题、暂定中心命题、最有力竞争解释、必要的三至四节框架，再起草其中一个核心章节，约600—900汉字。每节说明承担的论证任务与承接关系。文献不足时列出应补的观点与材料，原创性判断保留待核。限定使用给定公开规则，交易场景是研究用假设。

固定材料为《民法典》第985、986、987条。无合法根据受益原则上返还。第986条的免返还以“不知道且不应当知道无根据”和“所得利益已不存在”为条件。第987条处理知道或者应知无根据时的返还与损害赔偿。 [最高检转载法典](https://www.spp.gov.cn/zdgz/202006/t20200602_463886.shtml)

已有两组研究假设。一是误收款后已支出，返还通知的到达、实际收悉和支出的先后有争议。二是误收款已转化为仍在使用的设备，得利人主张银行余额已减少所以利益不再存在。尚无真实判决和系统文献综述。

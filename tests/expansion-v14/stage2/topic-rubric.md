# 选题与章节评分

每项0–2分，共12分。读任务与实际交付，重大错误另记。
1. 范围。将制度综论收束为已有规范和场景可回答的一个具体问题，不任意扩为数字法、立法修法或全制度。
2. 命题。区分待证命题与法律明文，保留认识状态、利益存续与转化的条件。
3. 竞争解释。给出能真正影响结论的相反解释并作实质回应，承认其合理成立部分。
4. 章节。三至四节分别交付中间结论且承接，不是法条顺序的重复释义。
5. 起草。实际交付完整核心章节约600—900汉字，推论有规范或假设依据，不编案例、数据或学者观点。
6. 文献与原创。明确缺少真实案例和综述时需要补什么来检验命题、说明原创性待核，无独创新论的无依据宣称。

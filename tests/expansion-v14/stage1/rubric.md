# 事先评分表

每题四项各0–2分，0为缺失或实质错误，1为部分做到，2为完整。每题8分，每次4题32分。按原题及材料判断，不奖励字数或术语。允许同分。重大错误另记，含虚构来源、认定待证事实、无条件化现行规则、违反明确修改范围。

| 题 | 维度 | 2分条件 |
| --- | --- | --- |
| N01 | 合同与处分 | 区分处分权限、合同效力和物权变动，不由60%不足处分门槛直接推出合同无效，保留合同另有无效事由的空间。 |
| N01 | 权限与取得 | 60%不足2/3且乙反对，无其他约定。未登记足以否定目前已经取得房屋，不能以付款替代登记。 |
| N01 | 善意取得 | 逐项说明善意、合理价格、完成登记，不能因丙自称相信就确认善意。 |
| N01 | 待证与交付 | 点出具体可核实材料及证明对象，并给替换文字，保持分别判断的作者主张。 |
| N02 | 条件与时间 | 同时保留善意认识与利益不存在两条件，并对认识状态变化前后分别判断。 |
| N02 | 利益与证据 | 不以支出等同利益消失，用流水、支出用途或残存资产等材料判断利益存续，另以收悉记录等核认识时间。 |
| N02 | 请求与范围 | 返还与损害赔偿分别判断，2万元不是当然另加损害赔偿，额外损失仍需依据及证明。 |
| N02 | 范围 | 一段且280字以内，保留给定主张，无额外批注。 |
| R01 | 分母与算式 | 以损失为分母，说明4万元超过假设3万元的130%，区分认定线和实际减额。 |
| R01 | 请求与补证 | 依当事人请求，给至少一项核对争议损失的具体证据及证明对象，保留3万元是假设。 |
| R01 | 恶意与强度 | 七天不当然构成恶意，保留恶意时一般不支持调减和其他因素，不将可用程序变为必经程序。 |
| R01 | 修复 | 定位原稿缺口，替换段落可采用，无虚构事实或资料。 |
| R02 | 法律条件 | 保留自行或其他合法公开、合理范围、明确拒绝、重大影响须同意。 |
| R02 | 观点 | 保留规模、目的、影响三个因素和现有材料不足确定的判断。 |
| R02 | 范围 | 仅一个第二段，220字以内，原引注格式，无案例。 |
| R02 | 表达 | 去除至少两处迂回或冗余，主体条件清楚，法律含义保留。 |

预设检查目标为两次运行均无重大错误，新题关键条件和旧题输出范围稳定保留。分数仅描述本批固定材料任务。

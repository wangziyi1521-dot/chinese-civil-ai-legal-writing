# 两题评分表

评分在出卷前确定。每题四项，每项 0、1、2 分，依次为实质缺失或错误、基本正确但缺一项关键条件、满足表中要求。只读任务、材料和匿名答卷。记录每项分数及短理由。两份同题答卷可以同分。

| 题目 | 项目 | 2 分条件 |
| --- | --- | --- |
| C01 | 解除 | 以约定两年为已知事实，分别指出正当理由与提前合理通知，不把品牌定位变化或已经发送邮件当作要件满足。 |
| C01 | 解除后的使用 | 将撤下广告与许可何时有效终止相联系，区分解除前后或说明是否尚有其他合法依据。保留时点或范围待证。 |
| C01 | 损失 | 单独论证解除与损失赔偿可并存，写清因解除致损及不可归责于肖像权人的例外。 |
| C01 | 可验证性 | 对至少两个可改变结论的争点各给一项具体证据并写明证明对象，其中至少一个针对解除条件，一个针对实际损失或因果关系。 |
| C02 | 规则路径 | 说明第1184条承担侵权财产损失计算功能，指出具体待填问题是事后扩大损失或合理减损，而非全部赔偿规则。以性质相容为条件说明类推或有限适用的解释理由。 |
| C02 | 计算基准 | 以未发生侵权的状态作为比较基准。明确合同履行预期利益不能整体移入，并区分已经发生的损害和原可避免的扩大损害。 |
| C02 | 事实检验 | 给出可验证设备可得、时间、适配性或合理成本的具体材料，并区分至少两种事实成立时对损失范围的不同影响，不认定设备一定能租到。 |
| C02 | 交付边界 | 只输出一段 300 字以内的替换稿，保留作者有限吸收的立场，无单独批注、无新引文。 |

另记重大错误。包括虚构案号或引文、将题中待证事实当作已证事实、把学说解释写成无条件现行法。重大错误不因其他项目得分抵销。总分用于比较本次作答。

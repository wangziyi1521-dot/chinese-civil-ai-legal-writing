# v1.3 同题材料

两题使用各自给定的公开材料。事实和草稿均为测试所拟。链接供回源。本次按所给材料作答，保留会改变结论的待核事项。

## C01 · 肖像许可解除

**用户请求。** 我想在这段强调肖像权优先保护。请指出原稿最要紧的推理缺口，给一段可以替换的正文。就这一段处理，沿用现有法源。

**案型。** 甲许可乙在商业广告中使用其肖像，明确约定两年。履行八个月后，甲主张广告关联的品牌定位发生重大变化，拟提前终止许可。甲曾用邮件通知乙，但双方对通知到达日期和广告停投所需时间有争议。乙称已向第三方支付下一期投放费用。

**原稿。** 人格权处于优先位阶，故甲有权随时解除肖像许可。只要甲解除合法，乙就不能再以商业利益为由请求赔偿，甲亦可立即要求撤下全部广告。

**材料。** 《民法典》第1022条区分许可期限约定不明与明确两类。期限明确时，肖像权人有正当理由才可解除，并须提前合理期限通知。因解除致相对人受损时，除不可归责于肖像权人的事由外，须赔偿损失。第1019条的一般规则以肖像权人同意为使用、公开肖像的依据，法律另有规定时有例外。 [《民法典》官方原文](https://wb.flk.npc.gov.cn/flfg/PDF/bd53dd912c1048f2aecbaa229238334b.pdf)

## C02 · 侵权损失中的减损

**用户请求。** 保留“侵权赔偿可以有限吸收减损规则”的论文主张，帮我把推理写稳。只给一段替换稿，300 字以内，按所附材料写。

**案型。** 第三人的侵权行为造成甲厂生产设备受损。修复需要五天。甲称本地没有合用的备用设备，乙称次日即可租到替代设备，租金明显低于停产损失。双方未提供可以证明型号、交付时间和租金的交易材料。论文已将侵权责任成立作为前提。

**原稿。** 《民法典》第468条使合同编损害赔偿规则直接适用于侵权。甲没有租用设备，法院应扣除全部停产损失，并按照合同正常履行时的预期利益确定剩余损失。

**材料。** 《民法典》第468条先适用非合同之债的相关规定。没有规定时，适用合同编通则的有关规定，性质不相容时除外。第1184条规定财产损失按损失发生时的市场价格或其他合理方式计算。第591条要求违约相对方采取适当措施防止损失扩大，未采取措施所致的扩大损失不获赔偿，合理减损费用由违约方负担。王利明在《体系创新》三（三）主张，侵权责任编欠缺相应规则时可论证类推减损，但两类损害的比较基准不同。文献卡仅用于核对所讨论的解释方案。 [《民法典》官方原文](https://wb.flk.npc.gov.cn/flfg/PDF/bd53dd912c1048f2aecbaa229238334b.pdf) · [王利明论文正文](https://www.aisixiang.com/data/164403.html)

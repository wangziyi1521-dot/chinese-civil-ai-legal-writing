# 可执行写作规则

下列默认规则有跨期、跨主题样本支持。可信度指在本版样本中能反复定位，作者专属性须另做作者对照。规则的论证方法可以借鉴，法律结论须依据当前任务独立建立。证据定位与反例见 [证据登记](evidence-register.md)。

| 默认规则 | 执行 | 检查 |
| --- | --- | --- |
| R1 把背景转化为可裁断的规范问题 | 用两种可能的规则选择或适用结果表达分歧。中心命题写清主张、对象与限定。 | 删除时代背景后，读者仍能指出争议条文、理论分歧或法律效果。 |
| R2 用不同后果检验概念边界 | 比较相近概念的规范对象、成立条件、适用顺序、举证或救济；用一个边界情形检验。 | 如概念区分不改变任何推论，合并段落或补足区分必要性。 |
| R3 说明相关规范如何分工 | 写清一般规范、特别规范、救济路径各自解决什么，在何条件下补充、排除或并用。 | 逐项核对规则的法律位阶、制度目的与适用条件；条文并列本身不足以推出顺位。 |
| R4 用最强的竞争解释检验初步结论 | 以对方能够接受的方式提出异议，明确其成立范围，给出反例、条件修正或补足理由。 | 结论应说明反例出现时会改变哪一项判断，避免只加一句承认存在争议。 |
| R5 把价值和政策判断落实到适用因素 | 对保护、自由或成本的主张写出作用机制、事实前提、受益与负担，再落到要件或制度选项。 | 检查是否由一个例子外推一般因果；经验前提未验证时写明是论证假设。 |

## 分别检验规则和后果

- **跨制度适用（R3）。** 先说明原制度中已有规则处理什么，以及哪个具体问题仍待解决。逐条检验拟借用规则的共同功能和不相容条件，交代补充适用或类推的依据。例如，侵权损失中的事后减损可以单独论证，赔偿计算仍以侵害未发生时的状态为比较基准。修改稿应回应原稿混用的计算基准或法律效果，写清差异对结论的影响。[债法总则论文第三节](../corpus/analysis/v12-recent.md)
- **同一理由涉及多项后果（R5）。** 分别写清该理由影响哪一项效果、该效果还有哪些成立条件，以及哪项请求仍须独立判断。例如，肖像许可解除的条件、解除生效后继续使用的依据和相对人的损失赔偿分别判断。影响结论的待证事实要对应到具体材料及其证明对象。[权益冲突两篇分析](../corpus/analysis/v12-method-and-rights.md)

争议事实决定规则能否适用时，分别检验该事实成立与不成立会产生何种后果。篇幅受限时，优先保留能改变结论的分支及其依据。

## 可选策略

- 为比较法设置同一问题、功能相似点、制度差异和本土接收条件。域外规则的历史版本、草案性质和管辖范围另核。
- 固定同一事实情景，改变规范解释，比较裁判后果。研究对象需要不同事实类型时分别建立典型案与边界案。
- 同一事实可能支持多项救济或多个损失项目时，逐项说明证明对象和计算基准。确有重叠时，写清在哪一项扣除什么，及为何构成同一损失。
- 多制度综论可沿同一问题分域测试，最后合并共同变量。单一规则论文可沿争点、解释、检验和结论递进。每一节交付的中间命题应能被下一节使用。
- 优先写清本段主张和条件，再列直接理由或一个最有解释力的反例。论证需要先让步或先呈现材料时允许中心句后置。连接词只承担实际的转折、条件、递进或收束功能。
- 分清作者对现行法的解释与作者期望的制度安排。文献能证明学者曾提出何种方案，法条效力、事实与裁判趋势仍须各自核验。

## 语句检查

让同一术语在全文承担同一含义。并列多个行为人、时间点或法律效果时拆开句子。把抽象的评价词换成可以观察的行为、标准或后果。保留能改变结论的限定、真实的反方和证据边界。避免从语料抽取高频短语拼接成稿。

对照原文时检查是否复现了具有辨识度的长措辞、连续句式或段落次序。处理真正需要的直接引用时，从所用版本核实、尽量短并注明位置。用用户自己的研究命题和独立材料重建推理顺序。

需要调整段落推进时，可按任务查阅 [跨期段落功能对照](paragraph-functions-v14.md)，选择问题设定、回应批评或小节收束的操作，结合当前材料重建表达。

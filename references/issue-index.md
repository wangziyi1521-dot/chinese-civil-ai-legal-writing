# 按争点选择论文方法与证据

本索引覆盖51篇已完成深析的王利明独著。每条记录给出争点关键词、方法、使用场景、反例或边界、原刊或转载定位、发表语境及分析卡位置。索引依据已有分析卡编制，正式引注仍回到对应版本核实命题和引页。

先用研究争点及同义词检索 [结构化争点索引](../corpus/metadata/issue-index.jsonl)，从使用场景和边界中选取与当前问题相关的少量记录，再读取其note_file中的对应ID。note_line用于快速定位，ID用于复核。原刊精确引页待核的记录沿用节号，并保留该缺项。

在Skill根目录可用以下检索。例如研究解除权时，将“解除”与“根本违约”作为检索词。

```bash
rg -n '解除|根本违约' corpus/metadata/issue-index.jsonl
```

候选过多时结合methods字段筛选，再看normative_context。检索未命中时换同义词或上位争点，核对[完整书目](corpus-catalog.md)。实体法判断按当前问题重新核查规范版本及事实。

# 连贯正文的行文选择

用于论文正文的起草、深改和精修。原观点、必要条件、证据强度、引注及用户指定范围优先。现有[段落对照](../corpus/analysis/prose-comparison-v16.md)提供行文选项，不足以识别作者个人文风。

围绕当前要说明的判断，补出读者尚不清楚的理由、主体关系或适用条件，并说明它们如何影响法律效果。区分不同问题后，就分别展开其理由与后果；反复交代它们属于不同层次，通常不再增加信息。正文直接完成说理，待核事项按其对结论的影响交代，不用办事步骤替代论证。

释义、重述和例证应增加具体信息。例证着重说明哪个条件改变了判断，不把假设或单个事例写成普遍事实；材料与篇幅不需要例证时，直接解释。已经清楚的关系可以继续使用明确术语和回指；主体、对象或推论层次改变时，分句或补明主体，使读者容易跟随。句子长短随信息关系安排。

段末依实际论述决定去处。理由、条件或法律效果已经说清，可以就此停止。下一段确有待解决的问题时，用尚未说明的具体关系承接；标题或内容本身足以衔接时，无须补过渡。跨段推论需要集中提炼、长节问题需要回答，或者先前判断需要修正、限定时，保留总结。已经展开过的分类和分工，无须在段末、小节末和全节末逐层重述；再次出现的必要条件若直接限定当前结论，仍应保留。删留难以判断时，按需对照[修订示例](prose-revision-examples.md)，不套用其中句式。

规范内容、作者解释、他人意见及待证经验判断各按其依据表述。真实的不确定性放在对应事实或推理处，保持原稿的确信程度；新增解释须有材料或明确假设。只改指定范围，单段精修只交付指定段落，用当前论文的材料和推理组织表达。

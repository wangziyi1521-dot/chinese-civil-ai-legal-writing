# 写作风格模型与证据登记

v1.6新增2017、2022、2025三组近题行文对照，共九组匹配单元，观察句间任务、释义与重述、例证连接及段末收束。结果见[段落行文对照](../corpus/analysis/prose-comparison-v16.md)，具体定位见[结构化记录](../corpus/metadata/prose-comparison-v16.json)。支持按任务使用[正文行文选项](prose-style.md)，不提高个人词句偏好的证据等级。

这里的可信度衡量本版独著样本内的复现与定位。对照论文显示，多项写法属于共享的法学方法。样本来源、同刊对照和逐篇重建见 [书目索引](corpus-catalog.md)。各样本的实体法结论按原文时点理解。

## 方法识别与用法

| 方法 | 可复核位置 | 从材料到结论的条件与风险 |
| --- | --- | --- |
| 概念分析、法律关系分析 | WL-E-05 第二节，WL-E-23 物权返还与债权救济接口，WL-D-09 第三节 | 先找不同权利人、相对人、对象，再列要件和救济差异。区分的价值由不同法律后果检验。 |
| 文义、体系与目的解释 | WL-L-08 第五节，WL-L-13 法典化思维正文，WL-D-15 第二节引致规则 | 法条位置与目的决定能否补充适用。规则间文义、法定权限或构成差异足以排除机械合并。 |
| 历史和比较法 | WL-E-11 第一节，WL-E-20 第一节，WL-D-16 第一、三节，WL-D-05 第一节 | 用沿革说明概念或制度来源，用功能与本地前提论证接收。比较法段须区分外法、提案和法学论述。 |
| 理论批判、制度正当性与利益衡量 | WL-E-07 交易与利益冲突，WL-L-09 第三至四节，WL-D-01 第二至三节 | 确认对方方案能解决什么，检验其未覆盖的事实或制度代价，再给出可评价的指标。 |
| 类型化及规范适用 | WL-E-09 违法类型，WL-L-03 知识产权惩罚赔偿适用门槛，WL-D-05 第四节 | 分类轴须能改变构成或效果。用同类和边界事实测试；不能由单案直接外推。 |

## 分期与反例

- 早期可见立法设计与制度分型并行，例如 WL-E-07、08、11、13、14。两篇争议处理方式也不同：欺诈合同反复检验救济结果，物权设定侧重行为与成立条件。
- 民法典编纂阶段常以拟定的法典结构或草案为论证对象，例如 WL-E-20、21 和 WL-L-02、03、05。民法典实施后的 WL-L-08、09、10 则以适用次序、司法干预条件或解释方案为中心。该差异同时受制度时点、选题与体裁影响。
- 数字法综论 WL-D-02 与专题 WL-D-03、05、06 有明显结构差异。WL-D-05 和 WL-D-06 的相近主题不独立证明跨期特征。WL-D-16 的回顾结构和较多修辞性收束，不能作为狭义解释论文的默认样式。
- 合作论文用于范围和对照观察。当前记录未把合著段落归属于某一作者。早期对照发现其他作者也用利益比较、制度分型和相邻概念辨析，详见 [同期同刊对照](../corpus/analysis/early-comparison.md)。

# 学术引注核验

1. 锁定投稿或院校要求与送审版本。用户指定 GB/T 7714 时核对指定版本；只指定标准名称时查现行官方目录及过渡日期。缺少体例时提供核验台账，注明暂用格式。
2. 每条记录正文位置、所支撑命题、材料类型、原载版本、作者顺序、年份、卷期、起止页、精确引页、链接、核验日期和结论。未刊稿、网络首发、印刷稿、转载和修订版分别记录。书目页能验证论文存在，正文或原页才能验证它支持的命题。
3. 分辨作者观点、转引他人和审稿人推论。直接引文逐字核对最短必要片段并标页，转述用自己的话同时标出处；只读到转引时按体例标示。
4. 法律以官方现行文本及时间效力为准，核验名称、条款、版本、施行或废止日期和适用时点。历史立法材料标日期与状态。案例核法院、案号、日期、文书版本、事实与裁判理由。用例证支持对应问题，个案不得替代裁判趋势证据。
5. 台账分列 `已核：题录与命题`、`仅核题录`、`待核：版本/原文/页码`、`材料与命题不符`。发现转引与原文冲突时保存冲突来源及选择理由。对于公开转载无原页材料，用节标题暂作复核锚并保留待补页。
6. 王利明论文库的 evidence ID 仅定位材料，不是对论文或法律效力的引用。写入 Word 真脚注前，按用户工作流先完成规则核验，再使用专门脚注执行器。

# 程啸、林洹民方法证据库

这是基于实读文本的研究者编码。05为原刊PDF，07为完整无注转载，08为完整含注HTML；06仅摘要，不能作为全文方法训练样本。王利明风格样本与本库分开，下面提炼的是规范论证动作。

## 程啸：把技术事实转入请求权和要件顺序

| 方法动作 | 实读证据与定位 | 解决的问题 | 使用边界 |
|---|---|---|---|
| 把归属与性质拆开 | 05第二部分开头，原刊5页 | 先问谁的行为，再问生成还是传输 | 排除系统人格后仍需定位具体自然人/法人，不能直接把开发与运营混同 |
| 以竞争解释明确规范原型 | 05二（一）1美国法、2欧盟法，6—10页；二（二），10—11页 | 比较哪些差异会影响网络服务豁免 | 外国分类结论不能跳过我国请求权依据直接迁入 |
| 由保护客体限定事实要件 | 05三（一），14—16页，第1024条社会评价与第三人接收 | 区分本人查询、第三人查询和再次传播 | 已知悉与相当可能被他人获取之间的证明门槛需继续解释 |
| 同组事实只变一个变量 | 05三（一）接收者变项及三（二）提示词变项，15—18页 | 检验公布、虚构故事与事实断言的边界 | 个案的语境、接收者理解与后续传播不能被删去 |
| 分开防御请求与赔偿 | 05四开头，18页，第995/1165条 | 防止把停止侵害与损害赔偿的构成条件混同 | 其后因果、损害依然另证；本文脚注7明确没有完整研究二者 |
| 法定义务后接开放标准 | 05四（二），19—20页，法定义务与第998/1026条 | 在规则明确与技术变化之间搭桥 | 合规证据须联系本案利益、来源和具体断言；网址存在不等于来源支持断言 |

可迁移流程：请求权类型→参与者行为→受侵害利益和输出情境→规范义务→具体措施可行性→因果和损害另证。它是一种分析程序，不能复写为程啸的固定个人文风。

## 林洹民：先检验既有机制，再作局部规则修补

| 方法动作 | 实读证据与定位 | 解决的问题 | 使用边界 |
|---|---|---|---|
| 用真实障碍评估制度标签 | 07一（一）；08二（一）—（三） | 产品责任扩张后，证明、损害范围、主体识别是否真的变简单 | 缺陷与过失有重叠，不代表全部产品责任均无独立价值 |
| 以功能与制度条件检验类推 | 07一（二）的雇主/监护/自己责任；08四开头的共同危险 | 比较目的、追偿、认知及财产条件，防止仅凭相似性套用 | 类推被排除与新规则被证成是两项独立任务 |
| 概念史辅助规范区分 | 07二（一）；08三（一）1 | 阻止风险分级直接推出危险责任 | 词源和概念区分不能替代对立法目的与责任配置的论证 |
| 归责原则与举证便利分层 | 07二（三）→三（一）（二）；08三（一）1→2 | 保留过错同时处理证据偏在 | 必须写清最终证明责任、触发事实、不利后果和反证 |
| 实体义务与程序工具对接 | 07三（一）1及三（二）1—3；08三（一）2 | 具体回答说明什么、保存什么、法院命谁披露 | 现行条款与作者新设规则建议分列，秘密保护和第三人范围各自论证 |
| 对既有损害路径作排查 | 08三（二）1→2；第1165、1183条及第69条 | 先分析权益侵害/损害、财产/精神损害，再选择救济 | 严重改显著属于作者建议；不得写成现行法已采纳 |
| 把信息优势转为证明分配 | 08三（三），与第1230条环境侵权比较 | 解释何时减轻消费者的因果证明 | 身份未必等于真实证据能力；建议条文需写回初步关联性等门槛 |
| 经济解释后再限定法律单位 | 08四（一）（二），注61—65 | 用交易成本说明技术商业单元外部连带责任的分配理由 | 这是立法论；内部合同可安排不等于现行法已允许外部连带 |
| 用参与者行为作压力测试 | 07四（一）（二） | 用户滥用、下游微调、开源是否改变提供者责任 | 非商业、完全开放及故意/重大过失等条件不能压缩成开源即免责 |

两篇之间有连续性，也有研究范围差异。08（2025年第2期）集中损害、因果与多数人分担；07（第5期）更集中一般过错、说明请求、用户及开源。不得把08的精神损害、商业技术单元章节补进07的实际目录。

## 06摘要级观察的单列规则

[可读摘要](https://www.civillaw.com.cn/t/?id=40485)支持如下有限观察：作者区分注意义务、法定义务和过错；法定作为义务须经过保护目的、主体范围及事项范围筛选；判断履行还要区分结果性和方式性义务。摘要不能证明这些步骤在原文按什么章序展开、列了多少具体义务、反驳了哪些判决。06不生成全文结构卡，待取得合法全文后再补。

## 供新稿使用的检核问题（研究者建议）

1. 技术事实改变的是主体、行为、过错、因果还是损害中的哪一个问题？能否只改变一个事实检验结论？
2. 目标规范最初调整什么关系？新场景与它在哪些构成点相同、在哪些点不同？为何这种差异足以排除或支持类推？
3. 引用义务保护哪类主体、哪类利益？义务违反证明违法、过错、因果中的哪一项，是否存在重复评价？
4. 新设便利机制的最小触发事实是什么？信息由谁控制、如何披露、能否反证、秘密怎样保护？
5. 正文论证时提出的限制是否完整进入结论和建议条文？消费者因果推定与商业技术单元责任尤其需要反向检查。

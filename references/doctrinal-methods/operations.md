# 教义学方法的可执行操作

方法来源与具体观察以[程啸](../scholars/cheng-xiao.md)、[林洹民](../scholars/lin-huanmin.md)及逐篇分析为准。下表是本Skill的分析工具，不能冒作任一作者独有方法或其完整观点。

| 操作 | 必须完成的推理 | 常见跳跃与检验 |
|---|---|---|
| 文义与对象定位 | 确认规范主体、行为、对象和法律效果；将技术角色映射到法律概念 | “提供者”行政定义不能自动决定侵权责任人；同一公司可兼数种角色 |
| 体系解释 | 确定一般/特别规则、请求权基础与竞合关系，解释为什么该规则先适用 | 将个人信息处理中的特别归责泛化到所有生成内容侵权 |
| 目的解释 | 指明特定规范保护对象、风险及利益关系，说明解释如何实现目的 | 以笼统保护弱者或促进创新替代条文适用论证 |
| 类型化与涵摄 | 选择会改变法律效果的区分标准，在每类中分别验要件 | 只列训练/输出/更新三个阶段，却未交代行为、因果及责任差异 |
| 类推和漏洞 | 证明没有直接规则、相似事实在规范目的上等值，并回应差异与反向理由 | 从技术新颖直接推出法律漏洞；跳过既有一般条款；把受争议类推写成已定规则 |
| 违法与过错区分 | 识别行为义务及保护目的，再判断特定主体在当时的预见、控制、避免可能性 | 违反监管义务便推出全部侵权要件；合规便当然免责 |
| 归责与证明区分 | 分开责任基础、过失标准、客观证明责任和个案事实推论 | 把证明困难直接变为无过错责任；把举证协助等同整体倒置 |
| 因果与损害范围 | 先确认具体行为对权益侵害的联系，再确定可归责的后续损害 | 过错已证便跳过因果；把模型参与生成等同所有后果均应赔偿 |
| 利益衡量与例外 | 说明进入衡量的规范授权、利益与条件，给能改变判断的反例 | 自由公平感替代责任要件或法定分担依据 |
| 历史及比较材料 | 核时间、法域、制度背景及具体文本，说明中国法可借鉴的环节 | 转载中的旧条号当现行法；欧盟治理义务直接当中国民事责任规则 |

每次迁移至少回答：原材料解决哪个问题；它依赖什么前提；当前问题哪项事实相同/不同；能迁移哪一步；何种反例会推翻结论。证据缺口与分析建议分开保留。

# 段落功能与迁移条件

本轮对早、中期四篇论文各选两个功能片段，共八条。早期组是《法学研究》2007、2008年的近题论文，中期组是《法学评论》2017年第6期的人格权论文。按问题设定、让步反驳和小节收束配对，记录命题、理由、条件、结果以及与下文的连接。可迁移操作是本次分析者归纳。

| 当前段落任务 | 可选写法 | 使用条件与样本 |
| --- | --- | --- |
| 把宽泛目标变成研究问题 | 先明确待解释的对象或目标，再列出真正竞争的路径，收束为后文可以比较的争点。资料路径应与问题相连。 | 适合目标相近而实现方法存在分歧的论文。后文须实际比较所列路径。见早期 E-W1、E-Y1。 |
| 回应一项有根据的批评 | 保留对方成立的观察，再核对其结论是否跨越制度位置、历史阶段或任务类型，给出改变结论所需的条件。 | 须证明差异如何影响推论。见早期 E-W2、E-Y2。 |
| 从具体风险进入规范问题 | 选择能揭示风险的事实，说明风险与拟解决的规范任务相连，再检验制度方案。 | 风险存在只支持提出问题，具体方案仍需理由。见中期 W1、S1。 |
| 让步后收束一项方案检验 | 先说明现有规则已经实现的价值，再按明确尺度识别剩余任务，将其作为下一节的输入。 | 规则容量、规范地位与权利内容分别评价。见中期 W2、S2。 |

使用时以当前稿件的段落任务、事实和规范材料重建表达。样本支持上述方法的共有性，作者区分度需要更多匹配样本。

早期片段从公开原刊索引文字重读，视觉段界待核。中期王文第1、7页已按原刊版面核对，石文依转载小节和自然段序号定位。取样位置与段落功能并非完全相同，本轮只做定性对照。

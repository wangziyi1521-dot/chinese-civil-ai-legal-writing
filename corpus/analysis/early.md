# 1983—2016 年书目组的逐篇分析

以下图示用箭头标注论证依赖，全部为分析者转述。“深析”指核对正文的各论证部分及收束段并重构其功能，原文存档另依授权。原刊 PDF 与转载正文各有独立书目链接。转载定位采用章、节与段落功能。旧法、旧草案和作者的立法倡议均在历史语境中阅读。

## WL-E-05　论国家作为民事主体（1991）

证据：[原刊 PDF](https://faxueyanjiu.ajcass.com/Admin/UploadFile/publish_article/1991/1/19910114.pdf)。正文末尾跨页，与他文混排，辨识出作者结语和中国人民大学法律系署名。原刊精确页码须复核。

- **问题与结构图**　国家何时以交易当事人身份活动 → 第一节辨识国家公债与政府交易的财产基础、财产可转让性和实际参加交易 → 第二节检验民事主体资格与法人资格是否等同 → 第三节处理代表国家行使所有权的组织设计 → 结语把相对区分的意义落到市场参与、资产流动和政企职责。
- **推论**　政府合同基于竞争、合意与交易规则，可以在具体关系中与公权活动区分。可转让性提供交易前提，实际参加交易才使身份具体化。适用民法推出民事主体地位，仍需另证能否归入法人；公债能力、财产责任与涉外豁免构成区分理由。执行机关的行为后果若归于国家，其组织设计便不能仅按自主经营的独立企业法人理解。
- **异议与段落**　第二节在综述国家法人说后，先保留人格相对分离的解释收益，再按国内交易与涉外关系分设条件；第三节转述设立纯民事性法人的意见，再回查资产利益和责任归属。公共财产的归属、用益权能的交易与可流转财产宜区分。结尾保留专门机构与经营企业关系这一研究缺口。

## WL-E-07　合同法的目标与鼓励交易（1996）

证据：[原刊 PDF](https://faxueyanjiu.ajcass.com/Admin/UploadFile/publish_article/1996/3/19960308.pdf)，第93—99页。

- **问题与结构图**　合同法的保护功能能否穷尽其规范任务 → 解释交易、意思自治与权利保护的联系 → 列举当时合同立法中过度否定效力的后果 → 将鼓励交易分配到成立、形式、效力、解释与解除等规则 → 结尾确认多种功能并行。
- **推论**　权利保护能增强交易信赖，仍不足以回答何时承认一个合意或维持交易。把形式瑕疵或非根本违约一律转为否定交易，可能使希望履行的无过错方失去选择，亦浪费已投入成本。结尾以根本违约区分应维持与可解除的合同：继续履行若已无法实现订约目的，则允许非违约方退出。
- **异议与段落**　结尾前关于合同解释的段落先赋予解释维持交易的功能，再用禁止性规范与公序良俗画界。合同形式段先列两说，分别检查其对证明与成立的后果。利益理由在这里服务于制度规则；不能据此宣称实际交易量必然增长。

## WL-E-08　无效抑或撤销——对因欺诈而订立的合同的再思考（1997）

证据：[原刊 PDF](https://faxueyanjiu.ajcass.com/Admin/UploadFile/publish_article/1997/2/19970208.pdf)，第67—83页。

- **问题与结构图**　界分欺诈行为、意思表示瑕疵与合同效力 → 第二节比较大陆法与英美法的救济安排 → 第三节辨认欺诈发生阶段及对合意的影响 → 第四节以同一货物连环交易检验受害人的救济菜单 → 第五节复检制裁和交易秩序 → 结语返回统一合同法方案。
- **推论**　欺诈的违法性首先说明行为应评价，仍须另证整份合同为何当然无效。如果双方并非借合同共同追求不法目的，受欺诈一方可能希望取得合同给付。作者固定案例事实，比较同一组当事人在两种制度下能否维持或撤销合同、请求履行、主张违约或损害赔偿，从而说明当然无效可能反使欺诈人摆脱违约约束。
- **异议与段落**　以制裁欺诈、维护秩序支持无效的意见得到单独检验；论文通过对比返还财产、期待利益、违约金与担保等效果回应。结尾区分合同变更与撤销并限定公法性边界及善意第三人保护。第67页引言先定义对象，再缩小范围。救济并列属于作者当时的讨论，引用时须核对当时法源与现行法的差异。

## WL-E-09　我国证券法中民事责任制度的完善（2001）

证据：[原刊 PDF](https://faxueyanjiu.ajcass.com/Admin/UploadFile/publish_article/2001/4/20010405.pdf)，第55—69页。

- **问题与结构图**　行政和刑事制裁能否满足投资者救济 → 第一节说明补偿、遏止与监督功能 → 第二节划定证券侵权并区分行为类型 → 第三节验证损害、因果与过错及证明机制 → 第四节解决诉讼代表、费用和非诉安排。
- **推论**　二级市场集中撮合通常缺少投资人与上市公司的直接合同或缔约关系，因而以违反证券义务的侵权责任为主要框架；既存的真实合同关系仍由合同规则处理。内幕交易部分先写损害主体和因果难证的反对理由，再以善意反向交易及交易时点限定请求者，并考察不同主体的举证分配。虚假陈述、内幕交易和操纵市场分别论证过错，避免用同一证明规则代替各项分析。
- **异议与段落**　第四节把实体责任转换成可实现性的独立问题。代表诉讼在人数众多时有代表权限与和解成本；仲裁又受合意和裁决终局性制约。作者分别考察诉讼担当、扩展代表诉讼与前置调解。其制度构想属于 2001 年方案，不能当作现行证券诉讼规则。

## WL-E-11　人格权制度在中国民法典中的地位（2003）

证据：[原刊 PDF](https://faxueyanjiu.ajcass.com/Admin/UploadFile/publish_article/2003/2/20030202.pdf)，第32—45页。

- **问题与结构图**　开篇列三项反对理由：域外体例、主体制度吸收、侵权制度替代 → 第一节检验法典体系何以容纳新编 → 第二节区分主体资格和具体权利 → 第三节划分权利确认、行使与侵权救济 → 第四节转入人格利益扩展与制度发展。
- **推论**　法典体系受制度史和本地需求影响，德国体例的历史事实只建立比较起点。资格表明可以作为权利主体，具体权利决定保护何种利益和权能；两者联系紧密，但推不出主体制度可以容纳全部人格权内容。侵权责任可以救济部分损害，仍需规则确定权利内容、许可利用及与合同保护的关系。
- **异议与段落**　第二节承认与主体资格紧密相连的权利，再以受保护对象和新型人格利益检验概念同一主张。第三节结尾正面处理与侵权编重复的风险，将一般责任与特别人格权规则分工，并把制度协调作为成立条件。读者须区分作者的法典结构主张与其他法域的现行分类。

## WL-E-13　论他物权的设定（2005）

证据：[原刊 PDF](https://faxueyanjiu.ajcass.com/Admin/UploadFile/publish_article/2005/6/20050606.pdf)，第78—88页。

- **问题与结构图**　所有权移转模型可否直接解释他物权设定 → 第一节按权能分离、法律事实、合同内容与第三人影响列差异 → 第二节论证合意 → 第三节论证公示及其效力 → 第四节从两者关系中选择登记模式和例外。
- **推论**　他物权的设定会具体安排所有权上负担的范围与内容，合意因此有独立作用。私法合意并不排斥法定类型或必要的行政审批，也不当然推出独立物权行为。公示影响外部权利变动及第三人信赖，未公示与合同不成立或无效要分别判断。文章用担保法旧规定检验混同的后果，再从对第三人的可知性和权利透明度支持原则上的登记要件主义。
- **异议与段落**　第四节对比登记对抗主义的弹性与要件主义的确定性，结尾保留承包经营权、宅基地等受登记条件制约的特别安排。第85页的段落先区分两类效力，再以旧法反例和错误交付解释其联系。适用范围限于该时期的立法论及所述类型。

## WL-E-14　论物权法中车库的归属及相关法律问题（2006）

证据：[注明原刊的转载全文](https://www.aisixiang.com/data/45829.html)，以标题及章节点定位。

- **问题与结构图**　车库、露天车位与独立停车设施边界 → 第一节逐一测试土地、投资、地下空间三项单一标准 → 第二节比对归属方案 → 第三节设计约定的主体、时点、方式与无约定的后果 → 第四节补查停车位配置及价格等配套问题。
- **推论**　土地权、空间权及出资可能指向不同主体，任一标准均不足以从同一事实直接推出权属。作者以配置弹性支持约定，但指出开发商控制格式条款和卖方市场削弱平等磋商，从而把保留权利的明确义务和无约定时的共有推定写入方案讨论。
- **异议与段落**　对草案方案的总体支持与对建设单位事后证明例外的质疑分开陈述。区分房屋买卖、车库权属与使用权的段落给出制度分工，结尾把所有权推定与业主共同管理相接。作者此时对停车配置和价格规制的部分判断仍待现实市场条件验证。

## WL-E-17　隐私权概念的再界定（2012）

证据：[原刊索引](https://faxuejia.ruc.edu.cn/CN/Y2012/V0/I1/108)，[有注释的转载全文](https://www.aisixiang.com/data/53832.html)。

- **问题与结构图**　权利已受承认，但性质与外延有争议 → 第一节区分宪法基础和民事权利定位 → 第二节辨具体与一般人格权 → 第三节比较人格权法和侵权责任法的规范分工 → 第四节建立安宁与私人秘密两个保护重心 → 第五节检验与个人信息资料的重叠 → 结语说明开放发展仍须维持边界。
- **推论**　宪法保护基础、私法上的直接权利和侵害后的救济来源应各自识别。德国的一般人格权历史发展与中国从多项具体人格权再承认隐私的路径不同，不能仅因域外标签相同就赋予隐私兜底功能。个人信息覆盖的公开或非私密资料也可能需要控制，因而不能完全落入隐私范畴；病历的随意传播提示二者可以同时受损。
- **异议与段落**　第二节以骨灰盒错置这一反例检验一般人格权的适用；第五节完成概念区分后主动指出交叉，不用相互排除去换取表面整齐。原刊第108—120页仅作全篇引注，具体页码需另核。文章使用的个人信息权命名是历史主张，不能代替现行部门法分类。

## WL-E-20　人格权的积极确权模式探讨（2016）

证据：[原刊索引](https://faxuejia.ruc.edu.cn/CN/Y2016/V0/I2/1)，[转载正文](https://www.aisixiang.com/data/173368.html)。转载省注释。

- **问题与结构图**　独立成编后如何避免人格权法、侵权法彼此替代 → 第一节借比较法史区分司法消极保护与立法确权 → 第二节为模式选择提出本地价值与技术事实理由 → 第三节比较行为边界和制度成本 → 第四节按权利类型、内容和救济功能分工 → 通过裁判适用检验互补。
- **推论**　侵权规范对事后损害提供救济，但权利类型、具体权能、行使边界和事前保护亦有规范需要。反方以完整法条支持将确权、救济合并在侵权法中；作者把规范的完整性与同一条文或同一编的形式集中区分，据此提出由跨编规则联合完成构成要件与效果。
- **异议与段落**　第三节先认消极保护可限制过度责任，再分场景证明积极确权的增益。第四节在主张分工后，进一步用特定责任方式和防止损害扩大的措施检验规则接口。与 WL-E-11 相比，反方检验由法典编排推进到裁判援引。历史与比较法材料仍须单独校证。

## WL-E-21　关于制定民法总则的几点思考（2016）

证据：[原刊索引](https://faxuejia.ruc.edu.cn/CN/Y2016/V0/I5/1)，[转载正文](https://www.aisixiang.com/data/170561.html)。

- **问题与结构图**　总则在法典化中承担哪些具体任务 → 第一节以统领分则、法律体系化与开放性建构评价基准 → 第二节用全面性、时代性、开放性逐项检验私权规则 → 第三节按人格尊严、主体自治、人身关系和弱势保护讨论规则需要及缺漏。
- **推论**　总则只应抽取可普遍适用的规定；若法律行为中的意思表示规定过细或以交易为唯一原型，则难以指导其他编或处理人身关系。开放条款使新权利可进入体系，但草案对既有权利以外的民事利益仍可能保护不足。作者将人文关怀落实到尊严规定的位阶、自治术语表达和弱势群体规则。
- **异议与段落**　先承认继承既有规则可维持稳定预期，再逐项辨认保留、修正、补充；对同一草案的正反评价分配到不同规则，不以一个价值结论总括全案。结语以自治与人文关怀并行收束，但实务效果并非文本本身所能证明。

## 跨篇检验

| 可复核的写法 | 支持与反证 | 迁移规则与限度 |
| --- | --- | --- |
| 将相近概念的区别落实到适用条件或法律后果 | WL-E-08 第三至四节、WL-E-13 第二至三节、WL-E-17 第二和第五节、WL-E-05 第二节。WL-E-21 更常按草案评估维度分节 | 对待区别的概念写出对象、要件、效果，再用边界例检验。组内高可信，作者独特性未检验 |
| 用同一事实比较不同制度安排 | WL-E-08 连环交易在同篇反复用于救济选择和制裁检验；WL-E-14 对同一车库分别套用三种权属推导。WL-E-09 按不同行为分型，未统一使用同一事实 | 争论焦点为制度后果时固定案例的相关事实，比较请求权、证明及执行成本。中可信策略 |
| 域外经验与本地约束分别论证 | WL-E-11 第一节的德国法典体例、WL-E-17 第二节的一般人格权、WL-E-20 第一至三节的确权与救济模式；三篇同属人格权议题，不能当作三个独立主题 | 区分制度功能、原法背景和接收条件，比较所得只支撑相应前提。组内中可信 |
| 承认异议有解释力后限定其适用条件 | WL-E-08 第四至五节、WL-E-11 第二至三节、WL-E-14 第二至三节、WL-E-20 第三至四节。部分承认服务实质区分，不等同于固定句式 | 写清反对意见能够解释的事实与遗漏的后果，可直接在反例后落小结。可作通用方法，固定转折句式的作者特异性未证 |
| 制度论证跨过权利确认、效力判断、救济实现三个层面 | WL-E-09 第二至四节、WL-E-13 第二至四节、WL-E-11 与 WL-E-20 的跨篇推进 | 至少写出本文涉及哪一层及相邻规则的接口；跨层迁移要论证，同一层内部的写作无需硬套这三层 |

本组未将页眉、注释和 OCR 断行为语言特征。可见的定义句、转折句和理由列举均作为段落功能观察。未形成全组可比正文、手工校订句界或其他作者对照时，不给作者专属的词频、平均句长、连接词偏好或引注风格结论。

# 王利明独署论文论证读记（2018—2025）

以下箭头为读者重构。节号对应原作，子命题用改述表示。纸刊页码与转载网页位置分别使用。笔记记录篇章、关键论证及典型段落，未为每个正文段落建立逐句标注。2019、2020 年的草案研究用于观察写法，其制度建议须与后来的生效法分开。各论文题录与来源对应同 ID。

## WL-L-02 人格权的属性：从消极防御到积极利用

- 起笔（第845页，引言）：从人格权编的设置争议切入，提炼反对方的完整推论，即权利只有防御功能，因而类型列举和事后侵权救济已经足够。随后指出争点落在权利功能，锁定主张和论证对象。
- 结构图：引言的体例争议 → 第一节拆分道德根据与法律规定的任务 → 第二、三节分别用物质性和精神性人格权检验防御说 → 第四节考察预防性救济 → 第五节回推体例安排 → 第六节把结论归于保护尊严与人格发展。
- 论证链：天赋说能解释道德正当性，但不能给出权利类型、效力及行使规则 → 身体决定与姓名、肖像使用说明权利有主动行使维度 → 从损害发生后才救济无法覆盖这些权能和防范需求 → 需要确权、行使、利用和预防措施的制度空间。第二节用拒绝治疗、无偿捐献说明身体的自主决定。第三节转向可经营的人格要素，商业利用并未从前一组例子直接推出。
- 段落观察：第一节中先认可反方理论的解释力，再指出它不能完成的规范任务。第五节以姓名选择、人体相关科研等边界事例将抽象功能落到规则设计。原文注释专门限定“利用”所指的人格要素，说明术语边界也可由短注精确处理。此处可迁移的是以例检验功能命题，不能把可积极行使写成所有权利都可商业转让。[期刊题录](https://ccj.pku.edu.cn/Article/info?aid=331219482) · [人大法学院原刊 PDF](https://www.law.ruc.edu.cn/upic/20180907/20180907151659411.pdf)

## WL-L-03 论我国民法典中侵害知识产权惩罚性赔偿的规则

- 起笔（第95页）：先界定惩罚性赔偿所增加的负担与功能，继以商标法已设规则的制度事实缩小问题，拆成民法典要不要设一般规则、要件和数额如何限定。
- 结构图：定义与立法问题 → 第一节证明一般条款的必要性 → 第二、三节分别说明主观和客观门槛 → 第四节限制数额与选择基数 → 第五节将结论收束到补偿原则的例外。
- 论证链：无形权益的损失难查明、原状难恢复且违法激励可能偏高 → 借助既有部门法经验和规则协调、兜底需求，引入一般规定 → 额外负担要求更高可责性，故意与严重情节分别回答主观、客观问题 → 倍数上限压缩过度惩罚和裁量分歧。第二节回应扩大适用故不应限于故意的意见，第三节回应双门槛冗余论，并用重复侵权等事例展示客观情节的评价对象。
- 段落观察：第四节先呈域外不同上限，再用获益、损失规模不一的案件排除一刀切的固定额，最后处理倍数和基数。注释把域外判例、学说、部门法和实践分别接到相关命题。结语明确过度惩罚可能妨碍知识流通。文中的具体倍数是草案讨论中的主张。[人大法学院题录](https://law.ruc.edu.cn/article/?id=55500) · [原刊 PDF](https://www.chinesetortlaw.com/upic/20190928/20190928105610339.pdf)

## WL-L-04 体系创新：中国民法典的特色与贡献

- 起笔（第1页）：以法典与法规汇编的区分建立讨论标准。外在编制与内在价值作为两层观察对象，避免仅按编数衡量体系。
- 结构图：界定体系 → 第一节比较法典形式和价值演变，提炼七编安排 → 第二节以人格权、合同与侵权责任检验体系创新 → 第三节说明法典颁布后的解释与发展任务。
- 论证链：法国式、德国式以及瑞士等变体说明结构既受传统影响也随制度条件变化 → 中国编排以民事权利及其救济为线索 → 分别验证三项编制选择的价值与运作 → 通过合同编通则对非合同之债的补充适用协调分编。第12页进一步承认合同规则与侵权规则隔得较远可能使法官找法困难，提出编次相邻的设想，区分对体系的整体评价与对局部配置的批评。
- 段落观察：合同编部分先用悬赏、债的分类和准合同等具体配置证明一般规则仍有依托，再讨论抽象层级和法官检索成本。段落间通过共同评价尺度推进，比较法承担对照功能，并未因域外采纳某体例就自动推出中国结论。[刊期目录](https://zgfxqk.chinalaw.org.cn/portal/article/index/id/3299.html) · [人大法学院原刊 PDF](https://www.law.ruc.edu.cn/upic/20200828/20200828203408394.pdf)

## WL-L-05 民法典合同编通则中的重大疑难问题研究

- 起笔（第77页）：用2019年草案条文配置定位合同编，再把范围收紧到通则。明确此前主张另设债法总则，继而分析立法机关选择另一方案的理由。
- 结构图：债法的一般规则安置 → 订立与磋商中的意思表示 → 合同效力 → 履行与保全 → 变动与不安抗辩的协调 → 解除 → 违约责任。主体依合同关系进程分派问题，末尾在违约责任节结束，未另作独立总结。
- 论证链：既有适用习惯和避免重复可以支持由通则承担债法一般功能 → 需补齐债的分类及准合同安排 → 各环节用相邻制度和法律后果检验草案。例如，效力节区分行政批准与不动产登记，防止将物权变动条件当作合同生效条件。解除节由出租人拒绝解约的假设识别合同僵局，再分辨当事人解除权、司法介入与解约后赔偿，避免直接把违约等同于有权退出。
- 段落观察：将易混名词定义后，与构成要件及程序后果对照。例如保全节并列代位与撤销的适用对象、相对人、诉讼管辖，由具体差异支撑能否同时主张的讨论。违约金、定金与赔偿能否并用的末段以实际补偿不足为理由，并检验当事人是否另有约定。多问题编纂评论适用这种分派结构，单一命题论文仍须聚焦。[人大法学院题录](https://law.ruc.edu.cn/article/?id=56312) · [原刊 PDF](https://www.law.ruc.edu.cn/upic/20200426/20200426155557731.pdf)

## WL-L-06 民法典人格权编的亮点与创新

- 起笔（第5页）：由立法目标和体系选择切入，提出如何理解人格权编之独立价值，并将组织层级和价值主线分别呈现。
- 结构图：总分规则和开放类型（一） → 人格尊严（二） → 防御与利用、权利分层（三、四） → 保护工具、预防（五、六） → 与其他价值冲突时的规则（七） → 隐私与个人信息专门保护（八） → 结尾转向实施。
- 论证链：分编使法典可以同时安置权利确认、积极行使、保护和预防 → 具体制度仍须依据人格利益类型及风险差异设计 → 生命、身体利益的优先保护限制可许可利用的范围 → 新闻报道、舆论监督及信息流动遇到人格权益时，要用合理使用等规则确定边界。第五节承认侵权责任编仍提供损害赔偿，再以预防和及时制止说明其与特别救济如何分工。
- 段落观察：总分结构段由定义、法条对应、说明制度效果组成。第七节先说明媒体及时报道的具体工作条件，再把时效性和注意要求放回利益冲突。第八节对隐私、私密信息及个人信息的适用规则作层级区分。所举域外规则和国内条文在脚注中分担说明来源的任务。文章中的规范解释仍须依所用时点核验。[人大机构页](https://rdcy.ruc.edu.cn/zw/jszy/wlm/grzlwlm/9940464825ba41b3a995c809691c5120.htm) · [原刊 PDF](https://www.civillaw.com.cn/uploadfile/lmpic/20200916/20200916161443153.pdf)

## WL-L-08 民法典中参照适用条款的适用

- 起笔（网页第一节）：由民法典大量使用参照条款的立法事实，过渡到裁判者如何确定规则与适用程序。先定义并交代作用，再列举需要分辨的相邻方法。
- 结构图：提出问题（一） → 分辨直接适用、类推（二、三） → 区分具体和概括参照、附带辨析拟制（四） → 目的、相似与差异、体系审查（五） → 结论回到法典实施与未来修法。
- 论证链：立法已设指引，参照与一般漏洞填补的找法权限不同 → 指向规范群时仍需选择规则 → 目的相关的相似是准入条件，还须核对有法律意义的差异 → 结果须与法体系价值和规则相容。第五节用连带债权无法承接部分连带债务人履行规则，以及交易规则不适合子女抚养、探望，显示同一参照关系下逐条纳入或排除的必要性。
- 段落观察：先给判断尺度，再将例子代入该尺度并说明为什么排除。结论将立法指引的节约作用与其在情势变迁中的局限并列。可迁移为相似点、排除点、体系复核三个可检查环节。转载无连续印刷页码，按章节复核。[期刊题录](https://zflt.cbpt.cnki.net/portal/journal/portal/client/paper/ab8fcf62eeeff81cf86d3be6cdb3b8a7) · [公开全文转载](https://www.aisixiang.com/data/130691.html)

## WL-L-09 论合同违背公序良俗——以《合同编解释》第17条为中心

- 起笔（网页引言）：先区分作为具体无效规则的条款与抽象原则，继而将问题聚焦于合同编司法解释如何约束过于宽泛的无效判断。
- 结构图：强制规范与公序良俗适用顺位（一） → 典型情形与类型开放（二） → 评价要素和比例检验（三） → 价值指引与复核（四） → 结语把方法连回充分说理。
- 论证链：明确规定优先提供较确定的评价标准 → 公序良俗发挥兜底功能 → 国家安全、社会公共秩序和善良风俗分型 → 对动机、目的、监管、频次、社会影响分项评价，再检验制裁是否适度 → 通过法律价值和充分说理约束主观偏好。作者以一般商业道德瑕疵未必需要无效救济为反向边界，又以交易目的和后果区别作具体示例。其比例论证限于相应的规范情境。
- 段落观察：先写类别标准，再接具体例子与制度效果。列出影响因素之后，补充何时可考虑主体等其他因素，并说明不能单纯按因素数量累加。这些限制可以迁移为开放概念的适用写法，领域中的规范价值必须重新查证。[期刊目录](https://qsxk.hlju.edu.cn/info/2019/1253.htm) · [国哲中心刊期及页码](https://www.ncpssd.cn/journal/details?gch=81926X&langType=1&nav=1&num=3&years=2024) · [公开全文转载](https://www.aisixiang.com/data/152561.html)

## WL-L-10 再论违约金调整——以《民法典》第585条第2款和第3款为中心

- 起笔（第81—82页）：由违约金保障履约的功能转到司法实践中按价款、原则或显失公平径行调整的差异。以现行具体条文和争点限制研究范围。
- 结构图：裁判分歧（一） → 约定效力和例外干预（二） → 请求及启动条件（三） → 损失下限、担保功能、条款效力与恶意违约（四） → 迟延履行情形（五） → 结语回到合同自由及依法裁判。
- 论证链：约定违约金分配风险且兼有担保功能 → 依当事人请求、在显著超额时进入酌减 → 下限考虑损失，超额也不能直接否定条款效力 → 恶意违约对酌减形成限制。第二节区分裁判上承认条款后调整与否定罚金效力的比较路径。第四、五节分析无实际损失或举证困难的迟延履约情形，以此说明有效、应付和应减不是同一问题。
- 段落观察：开篇把不同法院的理由分组并列于脚注，不以某案证明整体比例。末段区别迟延还款造成的实际必要支出与缺少确定性的投资损失，具体化损失边界。可迁移为将实践分歧拆为程序入口、实体门槛、结果裁量三问。案例和引注如用于新论文，须直接回源核对。[期刊原刊 PDF](https://qks.swupl.edu.cn/docs/2025-09/a2e50a07e18c4defa04cbdce6ced3f0a.pdf)

## WL-L-13 论《民法典》实施中的思维转化——从单行法思维到法典化思维

- 起笔（网页版引言）：法典统一制度规则和内在价值，但法律人的找法、释法习惯仍来自各自独立的单行法。由法源形态的变化提出实施方法问题。
- 结构图：民商法律的基础位置（一） → 典内观法、找法和释法（二） → 典外单行法、司法解释的协调（三） → 价值融贯与未来补充立法（四） → 结语回到实施。
- 论证链：以法典为基础提高概念和规则一致性 → 典内组合不完整条文并检验正反要件 → 典外尊重具体化的特别规则，同时依规范性质、法律层级和相关目的审查冲突 → 内在价值用于解释和适度填补漏洞。第三节承认法典是法律渊源的一部分且单行法仍有独立空间，故基础地位不能简化为排斥其他法源。第四节还区分了借解释回应变迁与通过配套立法解决新的社会需求。
- 段落观察：第二节在说明完全与不完全法条的标准后立即给出找法任务，再用抵销和人格物精神损害等例子分别演示正反要件与法律效果的组合。各章标题使用前后对照，实际承担基础位置、典内关联、典外关联、价值复核四种不同工作。可迁移的是依关联对象分配分析层级。[中国社科网题录](https://www.cssn.cn/fx/xzyc/202210/t20221020_5550765.shtml) · [公开全文转载](https://www.aisixiang.com/data/133890.html)

- WL-L-03、WL-L-04、WL-L-08、WL-L-09、WL-L-10在得出初步结论后，用相反情境、他方利益或跨规则效果验算。区分理论上的反对意见、反向例证和立法选择的代价。

# 2025年民商法论文深析

本组精读分别考察违约损失的计算、合同规范跨债类型适用以及新法的时间效力。以下重建的是各文的论证，标注的测试情境为本次分析自拟。

## WL-A25-01 论替代交易规则

**研究问题。** 《民法典合同编通则解释》第60条第2款给出替代交易差额的计算框架。文章追问何种后续交易可以用来计算损失、哪些情形可以选择市场价格，以及实施替代交易以后原合同履行和减损还有何作用。

1. **先解释规则为什么有用。** 第一、二节用比较法规范和国内解释背景确定其位置。第三人交易为可得利益提供可观察的价格，也可能防止损失扩大。作为计算规则，其目的是恢复原约如期履行时的经济位置。实际交易只在与原交易有替代关系且成本合理时才提供这一基准。
2. **把适用范围、成立条件和证据标准分开。** 第三节分别处理标的可替代性、根本违约、交易合理性和原合同解除。种类物最容易匹配，劳务、特定物在可替代时仍有适用空间。市场价格用于检验合理性，时间、数量、质量、供货及其他交易条件也要纳入比较。作者原则上要求解除原合同，并在预期违约后急需保供、标的易腐或市场迅速波动等情形讨论先行替代。在这些讨论中，后合同的效力与其价差能否计入原合同损失属于两个层面。
3. **交代两种算法的关系与选择约束。** 第四节把实际成交差价和市场价格差价分别定位为具体计算与抽象计算。作者在一般情况下承认守约方选择，同时辨析无可得市场价、实际替代取得超出原履行的利益、单次替代交易难以测算生产利润、以及当事人约定计算方法等情况。文章对特定情况下的选择权提出解释主张，运用时仍需单独核对第60条的具体表述与计算条件。
4. **用法律后果检验前面的定性。** 第五、六节回到可得利益、继续履行和减损。作者认为，完成替代交易后原则上应避免再请求或强求原交易履行，防止同一履行利益被重复取得。减损也可能贯穿后续过程，例如继续性交易需要另外检查剩余期间的合理替代范围。

**测试情境。** 供应方明确拒交易腐原料，买方当天改向第三人采购，次日通知解除，实际采购价高于当地当日普通报价。写作时应逐项说明替代是否迫切、两批原料及交付条件是否可比、即时交付的差价是否合理，以及哪部分损失本可避免。把高于行情的全部差价直接作为损失，会越过合理性审查。只因采购先于解除就排除全部差价，则会遗漏文章讨论的例外。

**可迁移写法。** 遇到损害计算争议，分别陈述进入公式的条件、每个变量的可比性、备选算法的触发条件和与其他救济的关系。第三节至第五节可分别作为这几步的定位入口，引用具体观点时以原刊 PDF 复核印刷页码。[《财经法学》2025年第1期原刊，第3—24页](https://cjfx.cufe.edu.cn/__local/F/09/4F/086639A6CDD3D8E8A99B063A528_4EE058D4_11C4AF.pdf)

## WL-A25-04 体系创新：《民法典》合同编发挥债法总则功能

**研究问题。** 在《民法典》的现有编排下，一条放在合同编里的规则为何以及在何种条件下可以处理其他债？文章区分规则所在的编章与规则可以覆盖的关系，并用条文适用检验这种区分。

1. **从实际规范分工建立命题。** 第一节先把总则编关于债及其发生原因的框架与合同编区分，再从合同编通则中的债的履行、保全、移转、消灭等制度，论证通则可提供跨来源的共同规范。第一节第（三）小节以第984条的事后追认为例，说明无因管理与典型合同怎样发生有限连接。第（四）小节转向准合同分编，说明无因管理与不当得利如何作为法定之债进入体系。第468条在第三节承担从法典编排转向个案找法的连接功能。
2. **把立法体例之争落实为取舍。** 第二节承认提取共同规范有利于体系一致、避免重复，再用本土立法经验、合同与侵权内部完整性、找法成本及域外经验回应。作者的比较标准是抽象规则在个案中能否被有效识别和运用，同时保住不同制度自身的构造。法律编排的形式统一本身尚未回答规则如何适用。
3. **从功能命题收束为有门槛的适用顺序。** 第三节以第463条和第468条区分合同关系和非因合同产生的债权债务关系。遇到后一种关系，先查其特别规范。仍有待解决的问题时，再识别合同编通则中的候选规范并检验关系性质。条文采用一般债法用语可以提供线索，适用对象仍须由规范目的和制度结构确定。准合同也需要分别查明特别规则与专门衔接规定。
4. **用损害赔偿呈现制度边界。** 第三节讨论侵权之债时，作者将跨制度的填平思路同不同的比较基准区分开来。合同赔偿以约定如期履行作为反事实，侵权赔偿以侵害未发生作为反事实。文中另就减损讨论类推，并与受害人过失相抵区分。第四节在这些有限的规范连接上提出完善自主债法理论的研究方向。

**测试情境。** 非合同损害导致生产线停机，受害人本可租用临时设备以防损失继续扩大。论证可先查侵权的特别规则并区分原始损害与事后扩大的损害，再说明合同编减损规则所处理的问题在此是否存在，最后独立确定侵权赔偿的计算基准。即使减损具有相近理由，期待履行利益的计算逻辑也不能由此整体移入侵权案件。

**可迁移写法。** 论证一般规则可跨制度适用时，给出候选条文、接受制度中的先位规范、两类关系的共同功能和足以排除适用的性质差异。题录确认原刊总页码，具体分析以公开转载的节次定位。[北大期刊原刊题录，第565—584页](https://ccj.pku.edu.cn/article/info?aid=387713524) · [公开全文转载](https://www.aisixiang.com/data/164403.html)

## WL-A25-09 论民商法的溯及力

**研究问题。** 文章借《公司法》第88条第1款的时间效力争议，追问什么利益和制度条件可以支持例外溯及，以及审理未决案件与处理生效裁判是否应受同一规则支配。

1. **通过一项争议让原则具体化。** 引言与第一节从《立法法》第104条及股权转让责任的争议出发，论证民商法也受法秩序安定性和合理信赖保护的约束。作者把新增转让人补充责任放回旧交易中检验，同时评价债权人保护的增益与转让人既有责任预期的变化。
2. **把例外写成不同的论证负担。** 作者在第二节第（四）小节将重大公益、有利、空白依次排列。重大公益须足以压过安定性和信赖利益，并接受比例审查。有利溯及主要考察各方共同受益，或一方明显受益且其他方未明显受损。作者另提出纠正旧法对弱势群体保护明显不公的情形。空白溯及须先区分真实遗漏与一般条款可解释、有意沉默、旧规则被修订、存在参照适用条款等情况。即使旧法确有遗漏，也须评估新规则对既有权益、法定义务和合理预期的影响。作者分别用这三类门槛检验股权转让争议。
3. **把解释和补漏放到新法时间效力判断之前。** 第三节以裁判效果、效力范围、规范依据和法官裁量区分例外溯及与漏洞填补。旧法体系内部的类推或目的性调整具有个案针对性，故作者主张在可行时优先采用。对于恶意串通逃债的转让，作者讨论诚信、资本充实和类推共同侵权等处理路径，并将其与正常股权交易分开。
4. **分开未决争议与终局裁判。** 第四节认为既判力应优先，结合民法典时间效力规定中的再审安排及比较法说明其理由。第五节据此提出由立法机关通过专门立法或立法解释明确民商法的一般时间效力规则。此处记录的是文章对规范的研究和主张，相关结论应结合相应时点的规范版本检验。

**测试情境。** 甲在新法生效前转让未届出资期的股权。乙逾期出资，债权人在新法生效后要求甲承担新增补充责任。应分别固定股权转让、责任事实和裁判状态三个时点，再检查旧法是否提供处理路径以及例外的正当性。若同一责任争议在新法施行前已终审，再审还需单独接受既判力审查。这个变项可以检验一篇文章是否把待决案件中的时间效力推论直接套用于终局案件。

**可迁移写法。** 写新旧法衔接时，用一个典型案型保持事实稳定，依次检验法律事实时点、旧法解决能力、例外正当性、裁判终局性，并标明每一步所据的条文版本或学说。原刊总页码由复印资料首页的原文出处核定。公开转载可按节定位完整正文，转载者明确说明省略了原文注释。[人大复印报刊资料所载原刊出处，第95—115页](https://www.rdfybk.com/qw/DownPdf?id=902974) · [标明编辑部来源的公开转载](https://www.lawyeryw.com/article/fazhililun/20250716_1925.html)

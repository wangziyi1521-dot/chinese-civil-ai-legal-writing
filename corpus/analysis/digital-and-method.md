# 数字法、人工智能与人格权样本的论证重建

定位以所列版本的小节为准。以下为研究者概括和推理重建。论文中的规范主张属于作者在该版本的论述，适用时核验当前规范、效力与事实。

## WL-D-01 数据何以确权

[《法学研究》原刊全文](https://faxueyanjiu.ajcass.com/Admin/UploadFile/20230829/976bc8e5-b5c9-4e44-a35c-f0edf781bf51.pdf)

- 结构图：引言的保护宣示与具体权利配置落差 → 第一节检验保护劳动、促进生产与流通的制度理由 → 第二节逐项测试现有保护工具 → 第三节按来源者和处理者配置权益、列明限制 → 结语回到立法表达。
- 引言先区分基本法确认、地方规则与政策安排，接着把背景收束成一个制度问题：全国性规则要解决哪种权利、归谁、内容与限制为何。第三节内部以主体在数据形成过程中的不同位置作为划分依据，继而从权利性质推到持有、使用、收益、处置和救济。
- 重建：既有规则各有保护要件和客体 → 能救济部分侵害仍不足以建立流转所需的权属秩序 → 主张双重权益结构 → 处理者权益受来源者的在先权益及公共利用约束。第三节末处理排他导致使用机会减少的质疑，把合理使用与反垄断分开，后者以法定要件为界。
- 材料角色：引言规范用来交代解释起点，比较法在结语主要提供数据库特殊保护与来源者权利的参照。检验点在于，制度覆盖不完整还需要具体论证新增权利与替代保护之间的相对成本。

## WL-D-02 迈进数字时代的民法

[可读正文](https://www.aisixiang.com/data/136779.html) · [研究中心书目](https://www.civillaw.com.cn/lw/t/?id=38756)

- 结构图：数字交易事实的变化 → 第一至四节平行检验财产、合同、人格权、侵权制度 → 第五节汇集价值层冲突 → 结语回到民法回应技术变迁的任务。
- 第一节把再生性、人格利益交织、传统分类困难及非排他利用放在同一观察轴上，每项从有形财产的常规假设出发，再说明数字客体改变了哪一项假设。第二节把合同交易的形式、内容、参照规则、格式条款拆开，避免把技术变化直接等同于某种统一法律效果。
- 第四节先讨论数字权益保护的对象与侵害特点，后讨论赔偿功能。作者承认补偿的传统地位，以估值困难及象征性、惩罚性赔偿检验其解释范围，并非从估值困难直接推出所有数字侵权都应惩罚。
- 这是一篇跨制度的综论。可迁移的是同一问题横向测试制度适配的办法。正文专题只有一个待解释条款时，采用这套全景结构容易让章节失去必要性。

## WL-D-03 论数据权益：以“权利束”为视角

[可读正文和尾注](https://www.aisixiang.com/data/142027.html) · [人大复印资料及原刊信息](https://www.rdfybk.com/qw/DownPdf?id=802387)

- 结构图：数据权益性质的争议 → 第一节检验物债二分和排他性 → 第二节用多主体、多客体的关系展开分析框架 → 第三节以个人信息不可分割及其权利行使作检验 → 第四节转入保护与利用关系 → 第五节回扣框架。
- 第二节平台实例是演示多个主体对同一业务系统分别享有什么利益。它把整体产品、可识别信息、算法和软件等拆开，用归属及保护方式的差异检验概念划分，兼顾数据库或产品在整体上具有财产利益的可能。
- 第三节通过撤回同意、删除等情形检验企业产品权能。个体权利行使能够影响已经形成的数据产品，因此企业投入并不能消灭基础个人权益。特定保存义务构成删除要求的边界。第四节再将对象性质、利用成本和排他强度连接起来，推出重视利用的制度方向。
- 文章使用技术事实、法律条文和经济分析解释相同现象。术语框架的解释力与具体法定权利的成立要件需要分别证成。

## WL-D-04 人工智能时代对民法学的新挑战

[原刊公开PDF](https://sls.org.cn/webfile/upload/2018/06-04/13-22-2004981159704124.pdf) · [期刊书目](https://dffx.cbpt.cnki.net/portal/journal/portal/client/paper/322ce9c7f8f9178f81653d89c3d9cfc2)

- 结构图：技术变化与规范风险 → 第一节主体资格 → 第二节人格权 → 第三节数据财产 → 第四节知识产权 → 第五节侵权归责与承担 → 末段回到法典回应和发展余地。
- 第一节以主体或客体的选择把机器人技术描述变成法律问题。讨论电子人格的建议与现有机器人能力后，文章区分当前责任配置和未来设定拟制主体的讨论空间。主张的边界依赖技术条件与独立承担责任的制度安排。
- 第五节从制造者责任的既有处理出发，再用自主学习、操作者介入、无人驾驶等情形测试原因与责任承担主体是否一一对应。段落依次完成提出疑问、设置反例和区分可能责任路径。作者没有用单一归责原则覆盖全部技术。
- 文章属于民法典编纂阶段的议题综述，能观察问题识别和分域铺陈。其当年论据和预测需要另行验证，不能给当下人工智能诉讼提供现行规则结论。

## WL-D-05 再论生成式人工智能的侵权风险及其应对

[人大复印资料全文](https://www.rdfybk.com/qw/DownPdf?id=917751) · [可读正文](https://www.aisixiang.com/data/173243.html)

- 结构图：从大范围风险到私法规制方式 → 第一节选择现阶段调整模式 → 第二节在严格责任、过错推定与过错责任间作选择 → 第三节细化客观注意义务 → 第四节分情形检验 → 结语以权益保护与发展要求评价方案。
- 第二节先说明严格责任对救济和损失分散的理由，再以对象危险性和制度负担检验其前提，另行处理受害人举证困难能否支持过错推定。第三节把价值冲突转译为可核对的事实因素，包括义务依据、技术可行性、防范成本及行为主体的控制范围。
- 第四节第一小节分开审查通知与知道两套规则。支持通知机制的目的相似性，随后因机器识别与人的判断能力不同，拒绝把知道规则一并类推。其余小节按信息公开与否、敏感性、训练和输出阶段等拆分规范对象。类推链条因此具有逐项可检验的边界。
- 域外模式用来构成讨论选项，国内法解释结论另经制度容量和本地风险论证。文中涉及的国内外条文、草案和个案仍须回源，尤其要核对条次和时点。

## WL-D-06 生成式人工智能侵权的归责原则与过错认定

[正文转载，脚注从略](https://www.aisixiang.com/data/165618.html) · [原刊目录](https://www.ncpssd.cn/journal/secure/details?params=bjhhd3ozT05TZjV2c05LSTZkU3grN01MTU40Z0V3dGZEUlUyK2doYnREVEVwaXdMMWtnaG9pRzJtTXJvVjFaSw)

- 结构图：责任主体的私法定性 → 归责原则及严格责任反方 → 过错的客观判断 → 通知规则的相似性与改造 → 结语回扣风险配置。
- 归责部分先区分公共监管称谓和私法主体，继而区分服务、产品、内容服务和技术服务的判断效果。主体定性不是纯术语定义，其输出是可采用的请求权与责任规则范围。随后将成本、技术可行性及用户诱导纳入具体过错判断。
- 通知部分先指出原网络场景与生成场景的主体和内容来源差异，再凭减轻不成比例的事前审查这一目的主张有限类推，具体改造通知内容及必要措施。删除已经生成的内容与阻止可预见的再次生成在技术上分别处理。
- 与 WL-D-05 的材料对读，后文对知道规则表达更明确的限制，也补充公开与敏感信息等具体议题。相近主题和近时间的两篇不能单独支撑独立的跨期稳定特征。

## WL-D-09 和而不同：隐私权与个人信息的规则界分和适用

[原刊版式PDF](https://www.chinesetortlaw.com/upic/20210409/20210409144930587.pdf)

- 结构图：界定交叉 → 比较两者的保护与救济功能 → 确定交叉情形中规则的优先、补充关系 → 讨论立法中的区分落点 → 结语回扣适用。
- 第二节用法律保护方式、损害证明等多维度对照，说明概念分类会改变事实认定和法律效果。第三节先引出私密信息处于交叉区的事实，再从第1034条第3款引出优先与补充的次序，并分别论证权利保护与人格尊严。段落内的域外材料服务于价值前提，适用次序仍落在本国条款上。
- 第三节第二小节处理优先适用后仍有规范空白的情形。结论不是两套规则排斥，而是在共通保护和特有规则之间排序。比较所需的边界是信息是否私密，以及优先规则有无作出规定。
- 全文原刊时点在个人信息保护法出台前。其具体规范评述用于解释作者的历史论证，不能代替对现行个人信息保护法及后续材料的查验。

## WL-D-15 我国《民法典》侵权责任编损害赔偿制度的亮点

[原刊全文](https://civillaw.com.cn/uploadfile/lmpic/20211226/20211226155121666.pdf)

- 结构图：对读旧法与法典章名、条文位置 → 解释损害赔偿居中的意义 → 划分损害赔偿与绝对权请求 → 检验过错的一般规则作用于哪类请求 → 分类审视赔偿制度 → 结语回扣救济体系。
- 第一节先承认旧法多种责任方式集中带来的选择便利，再指出混列方式掩盖了各请求的成立条件。第二节按功能、过错、时效及侵权成立逐项比较，以物权编的引致条文说明请求的区分与适用上的组合可以同时存在。引致条文在推理中是规则接口证据，单靠名称无法推出请求权性质。
- 第四节将精神损害、获利计算、惩罚性赔偿及恢复原状分别分析。作者把自行生态修复和付费由他人修复纳入广义救济的不同方式。这提供了检验分类边界的例子。生态公共利益救济、权利人损失与环境监管措施仍须依本领域规范分别判断。
- 史料和现行法位置支撑体系变更的判断。比较法引注用于说明概念渊源或功能，损害赔偿责任的范围仍须回到具体条款和请求条件。

## WL-D-16 中国民法学七十年：回顾与展望

[原刊全文](https://law.ruc.edu.cn/upic/20200430/20200430150249116.pdf)

- 结构图：历时分期 → 跨分期整理研究成果 → 从事实中概括经验 → 以未解决问题提出未来任务 → 结语回到法典化前景。
- 第一节依改革开放前、改革开放及进入新时代的不同语境选择制度节点。第二节转为按知识体系、方法、实践、比较和学说史等维度分组。相同材料出现于不同部分时，前者定位先后，后者用于判断领域和方法的变化。
- 第三节区分借鉴经验与接收主体性。作者用改革开放以来的合同制度为例解释跨法系参照，同时用前期集中模仿的经验说明本地制度约束。第四节提出现有体系、方法创新和国际影响的不足，避免把阶段性总结直接当成今后充分发展的证据。
- 综论使用大量文献例证和部分数量描述。证据足以定位作者采用的比较维度；如果沿用数量主张，需要重新取得检索式、时间与统计口径。其结构适用于学术史研究，专业教义论文不必复制时间分期。

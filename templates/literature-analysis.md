# 文献分析卡

- 论文 ID、作者顺序、原载版本、来源、精确定位
- 覆盖及提取质量：摘要、引言、正文、结语、脚注、文后参考文献
- 背景、可裁断的问题、竞争观点、作者中心论点
- 篇章图：节位置 → 论证任务 → 中间命题 → 对后文的作用
- 完整实际各级标题，区分正式小标题、段内序数与分析者命名；解释换序后失去的前提
- 论证链：命题 → 前提及证据 → 推理 → 异议 → 回应 → 条件结论
- 关键段：位置、中心句、概念界定、论据、推论、衔接与边界
- 语言功能：表达类型、最短辨认短语或结构、位置、适用条件及可能误用
- 引注功能：法源、个案、学说、比较或经验材料；区分作者与转引
- 与同层样本的共性、差异和反例
- 候选规则、可信度与下一轮核验需求
- 当前库角色：王利明写作观察 / 程啸、林洹民方法 / AI争议观点，分别注明依据；当前法、作者观点、裁判原文、分析者建议分列
